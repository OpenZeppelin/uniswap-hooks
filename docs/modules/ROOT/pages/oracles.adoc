= Oracles

Oracle hooks enable Uniswap v4 pools to function as price oracles by recording price observations and exposing oracle interfaces. For technical details, refer to the xref:api:oracles.adoc[API Reference].

== Base Oracle Hook

The xref:api:oracles.adoc#BaseOracleHook[`BaseOracleHook`] enables a Uniswap v4 pool to record price observations and expose an oracle interface. It transforms the pool into a price oracle by storing historical price data that can be queried by external contracts for time-weighted average price (TWAP) calculations and other oracle functionality.

== Oracle Hook with V3 Adapters

The xref:api:oracles.adoc#OracleHookWithV3Adapters[`OracleHookWithV3Adapters`] extends the base oracle functionality by automatically deploying adapter contracts that expose the Uniswap V3 oracle interface.

The hook automatically deploys adapters that:

* Expose `slot0`, `observations`, `observe` and `increaseObservationCardinalityNext` with V3 return shapes
* Support both standard and truncated price observations

WARNING: The adapters serve tick data only. They do not record `secondsPerLiquidityCumulativeX128`, so `OracleLibrary.consult` divides by a zero delta and reverts. They also implement only the four functions listed above, so a helper that calls anything else, such as `liquidity()` or `token0()`, reverts on an unknown selector. Confirm that your integration reads only ticks before you point it at an adapter.

NOTE: `slot0` returns placeholder values for `feeProtocol` and `unlocked`, and the truncated adapter reports the raw pool `tick` and `sqrtPriceX96` rather than truncated values.

TIP: If your integration reads ticks only, call xref:api:oracles.adoc#BaseOracleHook[`BaseOracleHook`] `observe` directly. It returns the standard and truncated tick cumulatives with no placeholder fields, so there is nothing to disregard.

These oracle hooks transform Uniswap v4 pools into reliable price oracles, enabling other protocols to query historical price data and calculate TWAPs directly from the pool's trading activity.
